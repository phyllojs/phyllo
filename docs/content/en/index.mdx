  <Row title="Markdown and JSX" href="/en/guide/writing" label="Writing guide">
    Articles are saved as `.md` or `.mdx` files, and the extension decides the syntax. `.mdx` supports React's JSX, so you can define components and write expressions. Components render to static HTML at build time.

    ```mdx
    import { useEffect, useState } from 'react';

    const getTime = () =>
      new Date().toLocaleTimeString('zh-CN', {
        timeZone: 'Asia/Shanghai',
      });

    export function Clock() {
      const [time, setTime] = useState('Loading…');

      useEffect(() => {
        const timer = setInterval(() => setTime(getTime()), 1000);

        setTime(getTime());
        return () => clearInterval(timer);
      }, []);

      return <time>{time}</time>;
    }

    Current **Beijing time**: <Clock />
    ```

  </Row>

  <Row reverse title="Themes and styles" href="/en/themes/customization" label="Customizing themes">
    The framework ships no built-in components. The interface and all styles come from the theme and can be fully customized. Themes can be published to npm for installation, or written in a local directory.

    ```tsx
    import { HeadResources, usePage, useSite } from 'phyllo';

    export default function Layout({ children }) {
      const site = useSite();
      const page = usePage();

      return (
        <html lang={site.lang ?? 'en'}>
          <head>
            <HeadResources />
            <title>{page.title}</title>
          </head>
          <body>{children}</body>
        </html>
      );
    }
    ```

  </Row>
