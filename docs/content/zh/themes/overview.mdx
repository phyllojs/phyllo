# 主题概述 \{#themes\}

主题决定站点的类型与外观，提供首页、导航、文章排版和交互。

## 主题负责什么 \{#responsibilities\}

一个主题负责以下内容：

- 决定页面的 HTML 结构与元信息。
- 提供首页、导航、文章列表和文章页的排版。
- 提供搜索、明暗模式和语言切换等交互。
- 通过 CSS 变量和内容组件提供可调整的外观。

文章提供内容，主题决定页面结构和样式。同一份内容更换主题后，站点的类型与排版都会改变。

## npm 主题与本地主题 \{#sources\}

主题以软件包的形式发布，主要来源有两种。npm 是 JavaScript 的软件包仓库：

| 方式     | 存放位置                             | 适用场景                   |
| -------- | ------------------------------------ | -------------------------- |
| npm 主题 | 发布在 npm 上，使用 Bun 安装到项目中 | 使用和更新已经发布的主题   |
| 本地主题 | 源码保存在项目的 `themes/` 目录中    | 为自己的站点开发或维护主题 |

两种主题都有自己的包名，在站点配置中填写包名即可使用，引用方式相同。

## 官方主题 \{#official-themes\}

官方主题目前提供 [文档主题](./docs/index.mdx)。`phyllo-theme-docs` 按章节组织内容，提供顶栏、侧栏、页内大纲、搜索和语言切换。

官方主题独立于框架发布。不使用某个主题的站点不会下载和构建该主题的代码。

## 安装与开发 \{#install\}

安装主题、填写包名和更换主题的步骤见 [安装与使用](./installation.mdx)。需要保留现有主题的外观并加入自己的改动时，使用 [自定义主题](./customization.mdx)。需要从零设计布局和交互时，使用 [编写主题](./development.mdx)。
