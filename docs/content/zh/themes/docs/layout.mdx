# 页面布局 \{#page-layout\}

文档主题根据页面用途提供不同布局。首页默认使用 `home`，文章默认使用 `doc`。只有需要改变默认排版时，才在当前页面的 frontmatter 中设置 `layout`。

## 布局的取值 \{#values\}

| 值      | 页面表现                                           |
| ------- | -------------------------------------------------- |
| `doc`   | 显示正文和大纲，所属导航章节决定侧栏和上下篇链接   |
| `home`  | 显示首页介绍和功能说明，有正文时以正文替换默认内容 |
| `page`  | 保留顶栏和正文样式，隐藏两侧栏、面包屑和上下篇链接 |
| `false` | 正文直接呈现在 `body` 中，不添加主题布局           |

`false` 是布尔值，不加引号。

## 文档页面 \{#doc\}

`doc` 是首页之外页面的默认布局。页面加入某个导航章节后，会显示该章节的左侧栏和上下篇链接，设置方法见 [组织导航](./navigation.mdx)。

未加入任何章节的页面只保留顶栏、正文和右侧大纲，常见问题页可以采用这种方式。

## 独立页面 \{#page\}

只需要顶栏和正文的页面，例如项目介绍，可以设置：

```md
---
layout: page
---
```

页面保留正文样式，隐藏两侧栏、面包屑和上下篇链接。`layout` 只影响当前页面的排版，不改变页面地址。

## 自定义排版 \{#custom-layout\}

使用 MDX 自行编排整个页面时，可以关闭主题布局：

```md
---
layout: false
---
```

正文直接呈现在 `<body>` 中，不添加顶栏、侧栏、大纲、面包屑和上下篇链接。正文容器和标题锚点按钮也不添加。

页面仍然保留完整的文档结构，标题、元信息和语言属性继续生效。构建资源和主题全局样式正常加载，MDX 交互不受影响。布局确定后，可以继续阅读 [修改配色](./styles.mdx)。
