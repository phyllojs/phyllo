# 文档主题配置 \{#docs-configuration\}

本页列出 `phyllo-theme-docs` 的全部字段。初次使用可以从 [使用文档主题](./index.mdx) 开始。

公共配置写在 `content/index.mdx` 的 frontmatter 中。多语言站点也保留这个文件，语言列表、顶栏标识、外部链接和搜索参数只需配置一次。

| 配置位置                                     | 字段                                              |
| -------------------------------------------- | ------------------------------------------------- |
| 根文件 `content/index.mdx`                   | `logo`、`links`、`locales`、`search` 和公共 `nav` |
| 当前首页，单语言为根首页，多语言为各语言首页 | `nav`、`hero`、`features`                         |
| 需要改变布局的页面                           | `layout`                                          |

各语言首页的 `nav` 替换公共导航，数组不会拼接。`hero` 和 `features` 只读取当前页面，不从根首页继承。

## nav \{#nav\}

- 类型：数组。
- 默认值：`[]`，不显示顶部导航。

每项需要 `label`，并从 `href`、`sidebar` 和 `items` 中选择一个：

| 字段      | 类型   | 用途                                     |
| --------- | ------ | ---------------------------------------- |
| `label`   | 字符串 | 顶栏或下拉菜单中的名称                   |
| `href`    | 字符串 | 普通页面链接或外部网址                   |
| `sidebar` | 数组   | 当前章节的侧栏分组，点击后进入第一篇文章 |
| `items`   | 数组   | 下拉菜单中的章节或普通链接               |

`items` 至少包含一项，每项使用 `label` 和 `href`，或 `label` 和 `sidebar`。下拉菜单只支持一层。

### 侧栏分组 \{#sidebar-groups\}

`sidebar` 至少包含一个分组：

| 字段    | 类型   | 用途                                 |
| ------- | ------ | ------------------------------------ |
| `label` | 字符串 | 侧栏分区标题，必填                   |
| `items` | 数组   | 文章链接或子分组，必填且至少包含一项 |

分组可以通过 `items` 继续嵌套，层数不限。分组不能设置 `href`。侧栏默认展开所有分组，文章链接与子分组可以混排。

顶部章节的入口是侧栏中的第一篇文章。上下篇按侧栏从上到下的文章顺序排列，跳过分组标题。面包屑按层级显示当前文章所属的分组。

### 文章链接 \{#sidebar-items\}

| 字段    | 类型   | 用途                                        |
| ------- | ------ | ------------------------------------------- |
| `href`  | 字符串 | 站内页面地址，必填，例如 `/getting-started` |
| `label` | 字符串 | 侧栏中的名称，可选，默认使用页面标题        |

文章链接不能设置 `items`。`href` 对应的页面必须存在，导航可以引用不同目录的文章。同一份导航中，一篇文章只能属于一个侧栏章节。

普通 `nav.href` 不会为页面分配侧栏。未加入章节的页面仍可访问和搜索，也保留右侧大纲，但没有左侧栏和上下篇链接。

## logo \{#logo\}

- 类型：字符串。
- 默认行为：顶栏只显示站点名称。

在根首页中配置图片地址：

```yaml
logo: /logo.svg
```

图片显示在顶栏的站点名称左侧，所有语言共用。它与首页的 `hero.image` 分别配置，标签页图标仍通过站点配置的 `head.link` 设置。

## links \{#links\}

- 类型：数组。
- 默认值：`[]`，不显示外部入口。

在根首页中配置，每项在顶栏显示为一个图标，所有语言共用：

| 字段   | 类型   | 用途                                  |
| ------ | ------ | ------------------------------------- |
| `icon` | 字符串 | 内置图标名称，必填                    |
| `href` | 字符串 | 链接地址，必填，支持 `mailto:` 等协议 |

支持的图标：

- 代码托管与包管理：`github`、`gitlab`、`gitee`、`npm`
- 社区与联系：`discord`、`slack`、`telegram`、`qq`、`email`
- 媒体与订阅：`x`、`bluesky`、`youtube`、`bilibili`、`rss`

主题根据图标提供无障碍名称，不接受 `label`。

## hero \{#hero\}

- 类型：对象。
- 默认行为：显示站点名称、描述和第一篇文章的入口。

| 字段          | 类型   | 默认行为                             |
| ------------- | ------ | ------------------------------------ |
| `title`       | 字符串 | 使用站点 `title`                     |
| `description` | 字符串 | 使用站点 `description`               |
| `image`       | 对象   | 不显示右侧图片                       |
| `actions`     | 数组   | 为第一个侧栏章节的第一篇文章生成入口 |

以上字段均可省略。未设置 `image` 时介绍区居中显示。未配置站点名称时，标题使用界面语言中的「文档」。没有侧栏文章时不生成默认入口。

`title` 和 `description` 只用于首页介绍区，不修改浏览器标题或 HTML 描述标签。

### image \{#hero-image\}

| 字段  | 类型   | 用途                 |
| ----- | ------ | -------------------- |
| `src` | 字符串 | 图片地址，必填       |
| `alt` | 字符串 | 图片的替代文本，必填 |

桌面端图片显示在文字右侧，窄屏下显示在标题上方。

### actions \{#hero-actions\}

| 字段    | 类型   | 用途           |
| ------- | ------ | -------------- |
| `label` | 字符串 | 入口文字，必填 |
| `href`  | 字符串 | 目标地址，必填 |

第一项使用主按钮样式，其余项使用次按钮样式。设置 `actions: []` 隐藏所有入口。

## features \{#features\}

- 类型：数组。
- 默认值：`[]`，不显示功能说明。

每项填写 `title` 和 `description`，两者均为字符串且必填，顺序与数组一致。

## layout \{#layout\}

`layout` 只影响当前页面，首页默认使用 `home`，其他页面默认使用 `doc`。

| 值      | 页面表现                                           |
| ------- | -------------------------------------------------- |
| `doc`   | 显示正文和大纲，导航章节决定侧栏和上下篇链接       |
| `home`  | 显示首页介绍和功能说明，有正文时以正文替换默认内容 |
| `page`  | 保留顶栏和正文样式，隐藏两侧栏和上下篇链接         |
| `false` | 正文直接呈现，不添加主题布局                       |

## locales \{#locales\}

- 类型：对象。
- 默认行为：不划分语言范围，不显示语言菜单。

主题根据根 `content/index.mdx` 是否声明 `locales` 区分单语言与多语言模式，与语言项的数量无关。未声明时，根文件作为首页。声明后，根文件只提供公共配置，不渲染页面内容。`layout`、`hero`、`features` 和正文不在根页面生效。

在根文件中声明语言范围：

```yaml
locales:
  /zh/:
    lang: zh-CN
    label: 中文
  /en/:
    lang: en
    label: English
```

键使用以斜杠结尾的 URL 前缀。`/zh/` 对应 `/zh` 及其下级页面，不匹配 `/zhongwen`。前缀中的非 ASCII 字符需要 URL 编码。

| 字段    | 类型   | 用途                                 |
| ------- | ------ | ------------------------------------ |
| `lang`  | 字符串 | HTML 语言标签，必填，例如 `zh-CN`    |
| `label` | 字符串 | 菜单中的语言名称，必填，例如「中文」 |

多语言内容分别放在独立目录中，范围不能使用根路径 `/`。语言标签必须合法且不能重复。

`locales` 设置语言属性和切换菜单，不创建页面，也不要求语言目录中必须有首页。需要语言首页时，在对应目录中编写 `index.md` 或 `index.mdx`。

菜单按显示名称自动排序，采用固定的英文排序规则，同名时按语言标签排序。配置顺序、浏览器语言和当前页面不会改变排列。主题按当前页面的 URL 决定选中项，不使用菜单第一项作为默认语言。

主题内置中文和英文界面，其他语言暂时使用英文界面文案。文章和菜单名称仍按配置显示，HTML 使用对应的语言标签。没有匹配语言范围的公共页面使用站点的语言默认值，菜单不选中任何语言。

语言配置不会创建跳转。未配置重定向时，访问根路径会显示空白页面。需要进入某种语言的首页时，在站点配置中填写 `redirects`，完整示例见 [多语言文档](./languages.mdx)。

## search \{#search\}

- 类型：`false` 或搜索配置对象。
- 默认行为：站点开启本地索引时使用本地搜索，否则隐藏搜索入口。

搜索配置只写在根首页中，所有语言共用：

```yaml
search:
  provider: local
```

`provider` 支持 `local` 和 `algolia`。选择 `local` 时，需要在 `phyllo.config.ts` 中开启 `search: true`，否则构建报错。主题中设置 `search: false` 可以隐藏入口，不改变 core 的索引开关。

`provider` 选择 `algolia` 时，需要填写以下参数：

```yaml
search:
  provider: algolia
  options:
    appId: YOUR_APP_ID
    apiKey: YOUR_SEARCH_ONLY_API_KEY
    indexName: your_docs
```

| 字段        | 类型   | 用途                   |
| ----------- | ------ | ---------------------- |
| `appId`     | 字符串 | Algolia 应用 ID，必填  |
| `apiKey`    | 字符串 | 可公开的搜索密钥，必填 |
| `indexName` | 字符串 | 索引名称，必填         |

站点需要安装 `algoliasearch`。所有语言共用这些参数，主题按当前页面语言过滤结果，无需在各语言首页重复设置。远程索引需要保存 `lang` 字段，并允许按该字段过滤。

使用 Algolia 无需开启 core 的本地索引。配置、爬虫记录和排查方法见 [配置搜索](./search.mdx)。

## 站点公共配置 \{#site-settings\}

站点名称、描述和 HTML 语言默认值写在 `phyllo.config.ts` 中。重定向、本地索引和头部标签也在这里配置，见 [站点配置参考](../../reference/configuration.mdx)。

主题为语言范围内的页面输出对应的 `html lang`。其余页面使用站点配置的 `lang` 作为默认值。
