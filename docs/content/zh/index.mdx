  <Row title="Markdown 与 JSX" href="/zh/guide/writing" label="写作指南">
    文章保存为 `.md` 或 `.mdx` 文件，扩展名决定语法。`.mdx` 支持 React 的 JSX，可以定义组件、写表达式。组件在构建时渲染为静态 HTML。

    ```mdx
    import { useEffect, useState } from 'react';

    const getTime = () => new Date().toLocaleTimeString('zh-CN', {
      timeZone: 'Asia/Shanghai',
    });

    export function Clock() {
      const [time, setTime] = useState('加载中…');

      useEffect(() => {
        const timer = setInterval(() => setTime(getTime()), 1000);

        setTime(getTime());
        return () => clearInterval(timer);
      }, []);

      return <time>{time}</time>;
    }

    当前**北京时间**为：<Clock />
    ```

  </Row>

  <Row reverse title="主题与样式" href="/zh/themes/customization" label="自定义主题">
    框架不内置组件，界面和样式全部来自主题，可以完全自定义。主题可以发布到 npm 供安装使用，也可以放在本地目录编写。

    ```tsx
    import { HeadResources, usePage, useSite } from 'phyllo';

    export default function Layout({ children }) {
      const site = useSite();
      const page = usePage();

      return (
        <html lang={site.lang ?? 'zh-CN'}>
          <head>
            <HeadResources />
            <title>{page.title}</title>
          </head>
          <body>{children}</body>
        </html>
      );
    }
    ```

  </Row>
